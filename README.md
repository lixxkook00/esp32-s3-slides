# esp32-s3-slides

**GOAT Desk Live** — the web slides for *Teach You a Lesson #8 – GOAT Desk: One Touch, Straight at Goal*, a team sharing session about my ESP32-S3 desk gadget, told as Ronaldo vs Messi.

A single static page (`index.html` + `media/`), no build step. Deploy on Vercel as a static site (Framework preset: **Other**, no build command, output directory `.`).

## Presenting
- `→` / `Space` / `PageDown`: next build or slide · `←`: back · `Home` / `End`
- `N`: speaker notes · `F`: full screen
- Penalty slides: click the answer (or press `A` / `B` / `C`)
- The scoreboard and votes are saved in the browser (localStorage); use **Reset match** in the bottom bar to start fresh.
